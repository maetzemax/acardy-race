# Vehicle Presets

Dieses Verzeichnis enthält vorgefertigte Fahrzeug-Konfigurationen.

## Wie man Presets benutzt:

1. Öffne dein Fahrzeug im Inspector
2. Aktiviere "Use Preset"
3. Ziehe ein Preset in das "Vehicle Preset" Feld
4. Das Fahrzeug übernimmt automatisch alle Einstellungen!

## Verfügbare Presets:

- **sport_car_engine.tres** - 400 PS Sportwagen-Motor
- **rally_car_engine.tres** - 350 PS Rally-Motor mit viel Drehmoment
- **supercar_engine.tres** - 600 PS Supersportwagen

- **6speed_sport.tres** - 6-Gang Sportgetriebe
- **6speed_rally.tres** - 6-Gang Rally-Getriebe (kurze Übersetzung)

## Eigene Presets erstellen:

Rechtsklick im FileSystem > New Resource > VehicleEngine/VehicleTransmission/VehiclePreset
